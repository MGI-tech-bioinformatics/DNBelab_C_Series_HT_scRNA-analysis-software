# HTML Report Display Issue and Solution

Dear Users,

We have recently received feedback from some users that the HTML reports generated by the analysis software cannot be displayed properly in browsers, showing blank pages or missing content. After technical investigation, we have confirmed that the issue is caused by the failure of the jQuery library address referenced in the HTML, resulting in script loading failure.

To ensure you can view the analysis results normally, we have organized the problem description and processing suggestions as follows:

## 1. Problem Description

The HTML report references an external jQuery library address:

```shell
http://lib.sinaapp.com/js/jquery/1.9.1/jquery-1.9.1.min.js
```

This resource is currently inaccessible, causing jQuery-dependent functions in the report to fail to load and preventing page content from displaying.

## 2. Recommended Replacement Method

Please replace the original jQuery reference address with the following available new address:

```shell
http://code.jquery.com/jquery-1.9.1.min.js
```

### Manual Modification Method

1. Open the HTML file using a text editor:

   - Windows: Recommended tools include Notepad, Notepad++, VS Code
   - macOS: Recommended tools include TextEdit (please set to display HTML as code rather than formatted text), Sublime Text, VS Code
   - Linux: Recommended tools include vim, nano

2. Find and replace the original jQuery path:

   The corresponding location is shown in the image below (using RNA analysis report as an example):

   <img src="./images/jquery.png" alt="image-20250728151550920" style="zoom: 40%;" /> 

   Replace the following content:

   ```shell
   http://lib.sinaapp.com/js/jquery/1.9.1/jquery-1.9.1.min.js
   ```

   With:

   ```shell
   http://code.jquery.com/jquery-1.9.1.min.js
   ```

3. Save the file and reopen it in your browser.

### Batch Modification Method (for Linux users)

If you need to perform batch replacement on multiple HTML files, you can use the following terminal command:

```shell
sed -i 's|http://lib.sinaapp.com/js/jquery/1.9.1/jquery-1.9.1.min.js|http://code.jquery.com/jquery-1.9.1.min.js|g' *.html
```

Note:

- Please execute this command in the directory containing the HTML files.

## 3. Analysis Software Web Report Template Update

The HTML report template location in the analysis software (dnbc4tools v2.1.3) is:

```shell
dnbc4tools2.1.3/lib/python/dnbc4tools/config/template/
```

You can execute the same sed command in this directory to batch update the jQuery reference paths in the templates.

```shell
cd dnbc4tools2.1.3/lib/python/dnbc4tools/config/template/ 
sed -i 's|http://lib.sinaapp.com/js/jquery/1.9.1/jquery-1.9.1.min.js|http://code.jquery.com/jquery-1.9.1.min.js|g' *.html
```

## 4. Future Arrangements

A new software package has been released with updated and fixed template files, while the version number remains unchanged (v2.1.3). New download links are provided in the installation documentation, and the HTML template issue has been resolved.

If you encounter any problems during the operation, please feel free to contact our technical support team for assistance.
