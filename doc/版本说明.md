# 版本说明

## dnbc4tools 发行记录

### 2.1.3 (2024年9月25日)

- **新特性**：增加RNA 5'端转录组分析和单细胞VDJ分析模块。

- 本次更新以tar.gz压缩文件形式发布，用户可直接解压，无需额外配置计算环境。

- 移除了软件的conda安装方式，容器版本暂未更新，用户可自行构建。

- 新增对gtf文件格式检查矫正的功能。

- 修复了scATAC在磁珠合并分析过程中出现的内存异常问题。

- 优化了RNA比对和区间注释的时间消耗。

  

### 2.1.2 (2024年4月24日)

- 调整了ATAC分析算法：基于Jaccard值进行合并，然后通过peaks区域片段进行细胞识别。
- 新增多个ATAC过滤参数，并支持生成BAM格式文件。
- ATAC数据库构建`mkref`中新增叶绿体参数，移除了生成的`tss.bed`文件中的线粒体和叶绿体转录区域。
- 调整了ATAC网页报告的样式，使其与RNA分析报告保持一致。
- 优化了软件安装流程，移除了R包的安装步骤。
- NA过滤逻辑调整为：从过滤包含"N"的片段改为过滤细胞条形码和UMI区域中含"N"的片段。



### 2.1.1 (2023年9月21日)

- 优化了RNA分析流程：使用oligo数据对磁珠进行合并分析后，再进行细胞识别。
- RNA细胞群体的标记基因展示优化为每个群体log2FC值前50的基因。
- 修复了容器版本中可能导致内存占用过高的问题。
- 修复了ATAC分析报告中部分图像无法显示的错误。



### 2.1.0 （2023年7月28日）

- **新特性**：增加ATAC分析模块。
- 优化了RNA参考数据库构建，新增`ref.json`文件记录数据库信息。
- RNA降维聚类部分由seurat替换为scanpy，提升了分析速度。
- 注意：升级至版本2.1.0需要重新更新参考数据库，可使用`noindex`参数跳过STAR索引的生成。



### 2.0.7 （2022年11月4日）

- 新增试剂版本和测序暗反应的自动识别功能，新增参数`chemistry`、`darkreaction`及`customize`替代原有的`cDNAconfig`和`oligoconfig`，并移除了`mixseq`参数。推荐使用自动识别功能。
- RNA cDNA文库fastq过滤时新增接头序列裁剪功能。
- RNA数据库构建（mkref）时，新增内存参数`limitram`，可根据基因组大小和染色体数量自动获取`genomeSAindexNbases`和`genomeChrBinNbits`的值。



### 2.0.6 （2022年9月19日）

- 新增singularity容器版本。

- 修复了无法复现分析结果的问题，现在可以确保多次分析结果一致。
- 修复了cDNA文库Q30读数统计中的错误。
- 修复了`barcodes.tsv.gz`中的条形码数量与估计细胞数量不一致的问题。



### 2.0.5 （2022年8月19日）

- 新增Docker镜像版本。
- 修复了注释逻辑统计的错误。
- 调整了HTML报告中的部分描述。
- 降低了GTF文件格式要求，若文件中没有`gene_name`，则默认使用`gene_id`，没有`transcript_name`时使用`transcript_id`。
- 调整了UMI矫正逻辑。
- 修复了GTF过滤时要求首行必须包含`#`的错误。



### 2.0.0 （2022年6月20日）

- 新增命令行模式支持。
- 修复了因空beads相似性分析导致的流程中断问题，以及细胞数量较少时QC和聚类分析中的错误。
- 优化比对和区间注释的时间及内存消耗，默认加入内含子reads用于表达分析；细胞识别步骤中默认使用emptydrops方法；优化了结果报告中的图像展示效果。
- 新增饱和度分析、细胞聚类注释及Fraction Reads in cells结果统计。
