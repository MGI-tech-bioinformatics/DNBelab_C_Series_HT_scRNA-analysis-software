    版本说明¶

    DNBelab C Series™ HT 单细胞分析软件官方版本更新记录

    最新版本 • 当前版本详情 • 版本选择指南

    最新版本 ¶

    dnbc4tools 3.1（2026-04-03）- 查看详情

    主要更新： - 新增多组学模式：支持 RNA + VDJ 联合分析 - 修复 RNA 模块关键问题 - 优化 bam2fastq 与 fqsubC4 工具性能

    当前版本详情 ¶

    3.1（2026-04-03） ¶

    多组学分析¶

    • 新增多组学模式：支持单样本多组学分析，可执行 RNA + VDJ 联合分析或单组学独立分析。

    RNA 功能增强¶

    • 一致性细胞分析：新增参数 --consistent_cells，可复用已有合并结果和细胞分配信息，保持下游分析一致性。

    RNA 问题修复¶

    • Fraction Reads in Cells：修复指标计算错误。
    • 双物种数据库：修复物种名称包含下划线时的异常问题。

    性能优化¶

    • 速度提升：优化 `bam2fastq` 与 `fqsubC4` 运行效率。

    CLI 修复¶

    • 帮助信息统一：统一各模块帮助文本与参数展示格式（含 multi 命令）。

    过往版本说明（3.0 及更早） ¶

    以下为过往版本更新记录（按时间倒序）：

    3.0（2025-12-18）

    RNA 模块增强

    • 优化比对与注释优先级，提升定量准确性。
    • 新增含 N 碱基 barcode 纠错逻辑。
    • 增强双物种参考库构建和分析支持。
    • 丰富 BAM 与矩阵输出字段。
    • 新增 minumi，优化 expectcells 自动估计。

    ATAC 模块增强

    • 扩展 Q30、插入片段长度等质控指标。
    • 升级比对引擎并优化 barcode 纠错与 BAM 输出。

    VDJ 模块增强

    • 改进单细胞组装与注释流程，提高全长 contig 恢复能力。
    • 优化内存管理，减少预加载压力。
    • 增强 contig_annotations.csv 与报告内容。
    • 支持非人/鼠物种自定义参考库构建。

    跨模块改进

    • 统一 customize 参数行为。
    • 优化中间文件组织，降低磁盘占用。
    • 弃用 process 参数并自动清理中间文件。
    2.1.3（2024-10-09）

    新增功能

    • 新增 RNA 5' 转录组分析模块
    • 新增单细胞 VDJ 分析模块
    • 新增 GTF 文件格式检查与修正功能

    安装与性能

    • 以 tar.gz 发布，减少环境配置依赖
    • 移除 conda 安装方式
    • 修复 scATAC 合并过程中的内存异常
    • 优化 RNA 比对与注释性能
    2.1.2（2024-04-24）

    ATAC 改进

    • 细胞识别策略由 Jaccard 合并升级为 peak fragment 驱动
    • 新增多个过滤参数并支持 BAM 输入
    • 增强参考库构建中的叶绿体处理
    • 统一 RNA/ATAC 网页报告风格

    通用改进

    • 简化安装流程（移除 R 包依赖）
    • 优化 barcode/UMI 区域 N 碱基过滤逻辑
    2.1.1（2023-09-21）

    RNA 流程优化

    • 细胞识别前先使用 oligo 数据执行微珠合并分析
    • 优化 marker gene 展示逻辑（每群体展示 top50）

    问题修复

    • 修复容器环境下的高内存占用问题
    • 修复 ATAC 报告图像显示异常
    2.1.0（2023-07-28）

    主要新增

    • 新增 ATAC 分析模块

    RNA 更新

    • 参考库构建流程优化，增加 ref.json 信息文件
    • 降维聚类由 Seurat 切换为 Scanpy 以提升速度
    2.0.7（2022-11-04）

    自动化与参数

    • 支持试剂版本和暗反应周期自动识别
    • 新增参数：chemistry、darkreaction、customize
    • 移除 mixseq 参数

    技术改进

    • 增加 RNA cDNA 文库接头序列切除
    • 新增 limitram 以优化参考库构建内存控制
    2.0.6（2022-09-19）

    容器与稳定性

    • 新增 Singularity 支持
    • 修复结果一致性相关问题
    • 修复 cDNA 文库 Q30 与 barcode 统计异常
    2.0.5（2022-08-19）

    容器与格式兼容

    • 新增 Docker 版本
    • 放宽 GTF 字段格式要求
    • 优化默认参数与异常处理逻辑
    2.0.0（2022-06-20）

    主要发布

    • 新增命令行工具支持
    • 增强流程稳定性与异常处理能力
    • 优化比对与注释性能
    • 默认使用 emptydrops 细胞识别方法
    • 新增饱和度分析与细胞类型注释

    历史版本获取¶

    旧版本的下载链接与安装说明可参考旧版安装指南。更多发布信息可参考 GitHub Releases。

    发布说明：
    Stable：推荐用于生产环境，会持续接收安全更新与关键缺陷修复。
    Release Candidate (RC)：功能基本冻结，适合最终验证与预生产测试；可能仍有小范围修复。关键生产任务建议优先使用 Stable。
    Beta：仅用于测试与开发，接口和行为可能变动。

    详细安装与使用说明请参考安装指南与快速开始。
