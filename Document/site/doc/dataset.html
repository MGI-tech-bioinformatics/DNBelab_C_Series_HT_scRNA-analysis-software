    DNBelab C 系列示例数据集¶

    示例数据托管在 CNGB（中国国家基因库）。当前提供小鼠样本数据。

    分析类型 样本说明 项目链接
    scRNA-seq v3 小鼠样本，包含分离的 cDNA 和 Oligo 文库。 CNP0005575
    scVDJ-seq 小鼠脾脏组织，包含 5' RNA、TCR、BCR 数据。 CNP0006116
    scATAC-seq 小鼠脑组织样本。 CNP0004369

    数据使用说明¶

    scVDJ 使用说明：如果不需要分析 5' RNA 数据，可直接从对应 FTP 目录下载 singlecell.csv 作为 VDJ 流程输入。

    通用说明：访问项目链接后，在 “Sample” 或 “Experiment” 页面中可找到原始数据 FTP 下载地址。

    示例：在 CNGB 项目页面中定位 FTP 下载链接。
