🔬 主分析流程 (run)

📊 用法 

$ dnbc4tools rna run -h
usage: dnbc4tools rna run [-h]

optional arguments:
  -h, --help            show this help message and exit

Input Files:
  Choose ONE input method: either --fastqs (directory) OR all four individual FASTQ files (-c1, -c2, -i1, -i2).

  --fastqs <DIR>        Directory containing cDNA and oligo FASTQ subfolders (e.g., cDNA/sample_cdna_R1.fastq.gz, oligo/sample_oligo_R1.fastq.gz). The pipeline automatically detects paired-end files. Example: ./fastq_dir
  -c1, --cDNAfastq1 <FILE> [<FILE> ...]
                        Read1 FASTQ file(s) for cDNA (supports wildcards and comma-separated lists). Used for gene expression data. Example: sample1_R1.fastq.gz,sample2_R1.fastq.gz
  -c2, --cDNAfastq2 <FILE> [<FILE> ...]
                        Read2 FASTQ file(s) for cDNA (supports wildcards and comma-separated lists). Must match --cDNAfastq1 order. Example: sample1_R2.fastq.gz,sample2_R2.fastq.gz
  -i1, --oligofastq1 <FILE> [<FILE> ...]
                        Read1 FASTQ file(s) for oligo (supports wildcards and comma-separated lists). Used for barcode merging. Example: sample1_oligo_R1.fastq.gz
  -i2, --oligofastq2 <FILE> [<FILE> ...]
                        Read2 FASTQ file(s) for oligo (supports wildcards and comma-separated lists). Must match --oligofastq1 order. Example: sample1_oligo_R2.fastq.gz

Basic Settings:
  -n, --name <STR>      Unique identifier for the sample (e.g., sample1). Used for naming output files and reports.
  -g, --genomeDir <DIR>
                        Path to reference genome directory containing STAR index files. Example: ./genome_index
  -o, --outdir <DIR>    Output directory for results and reports [default: current directory]. Example: ./output
  -t, --threads <INT>   Number of CPU threads for parallel processing [default: all available cores] (e.g., 16).

Filtering Settings:
  --calling_method <STR>
                        Cell detection method [default: emptydrops]. Options: barcoderanks, emptydrops.
  --expectcells <INT>   Expected number of cells to guide detection [default: auto] (e.g., 3000).
  --forcecells <INT>    Force pipeline to use exactly this number of cells, overriding detection (e.g., 5000).
  --minumi <INT>        Minimum UMI count per cell to retain [default: 1000].

Library Settings:
  Configure sequencing library settings for barcode, UMI, and read structure.
  Auto-detection is recommended for chemistry and dark cycles.
  Use --customize twice for cDNA and oligo patterns, e.g., 
  --customize "cb,R1:1-10;cb,R1:11-20;umi,R1:21-30;R1,R2:1-100" --customize "cb,R1:1-10;cb,R1:11-20;R1,R2:1-30".

  --chemistry <STR>     Library chemistry version [default: auto]. Options: scRNAv1HT, scRNAv2HT, scRNAv3HT, scRNA5Pv1, auto (automatic detection).
  --darkreaction <STR>  Dark cycle setting for cDNA and oligo libraries [default: auto]. Provide two comma-separated values: <cDNA>,<oligo> Each field options: auto (automatic detection), R1R2 (both reads), R1 (Read1 only), unset (no
                        dark cycles). Examples: R1,R1R2; R1,R1; unset,unset.
  --customize <STR>     Custom read structure for barcode, UMI, or sequence extraction, format: <type>,<read>:<start>-<end> separated by ';'. Types: cb (cell barcode), umi (UMI) R1/R2 (sequence). Examples:
                        "cb,R1:1-10;cb,R1:11-20;umi,R1:21-30;R1,R2:1-100"

Analysis Settings:
  --no_introns          Exclude intronic reads from the expression matrix to increase specificity.
  --end5                Enable 5'-end scRNA-seq analysis for 5' gene expression profiling.
  --no_bam              Skip BAM file generation to save time and disk space.
  --sample_read_pairs <INT>
                        Subsample this number of cDNA read pairs for analysis (e.g., 1000000).

🟢 输入文件参数

📁 选择一种输入方式：基于目录 OR 单独指定文件

参数 描述与配置
--fastqs

🔄 方式1

📂 FASTQ 文件目录

方法：基于目录的输入，自动检测
功能：流程自动检测 cDNA 和 oligo 文件夹中的配对文件
互斥：不能与单独的 cDNA/oligo 文件同时使用
目录结构要求：
  • cDNA 文件夹：包含 cDNA 文库的 R1 和 R2 文件
  • oligo 文件夹：包含 oligo 文库的 R1 和 R2 文件
  • 文件命名：需要遵循标准命名规范
示例： ./fastq_directory
-c1, --cDNAfastq1

🔄 方式2A

📄 cDNA Read1 FASTQ 文件

输入：cDNA 文库的 Read1 FASTQ 文件
支持：通配符和逗号分隔的列表
用途：用于基因表达数据分析
要求：必须与 cDNAfastq2 参数配对使用
示例： sample_cDNA_L01_R1.fastq.gz,sample_cDNA_L02_R1.fastq.gz
-c2, --cDNAfastq2

🔄 方式2B

📄 cDNA Read2 FASTQ 文件

输入：cDNA 文库的 Read2 FASTQ 文件
支持：通配符和逗号分隔的列表
顺序：文件序列必须与 cDNAfastq1 完全匹配
要求：必须与 cDNAfastq1 参数配对使用
示例： sample_cDNA_L01_R2.fastq.gz,sample_cDNA_L02_R2.fastq.gz
-i1, --oligofastq1

🔄 方式2C

📄 oligo Read1 FASTQ 文件

输入：oligo 文库的 Read1 FASTQ 文件
支持：通配符和逗号分隔的列表
用途：用于条形码合并和细胞识别
要求：必须与 oligofastq2 参数配对使用
示例： sample_oligo_R1.fastq.gz
-i2, --oligofastq2

🔄 方式2D

📄 oligo Read2 FASTQ 文件

输入：oligo 文库的 Read2 FASTQ 文件
支持：通配符和逗号分隔的列表
顺序：文件序列必须与 oligofastq1 完全匹配
要求：必须与 oligofastq1 参数配对使用
示例： sample_oligo_R2.fastq.gz

⚠️ 输入方式选择：

  • 🔸 方式1： 使用 --fastqs 指定包含 cDNA 和 oligo 子文件夹的目录
  • 🔸 方式2： 使用 -c1/-c2/-i1/-i2 分别指定 cDNA 和 oligo 的 R1/R2 文件

📌 格式要求：

  • 多个 FASTQ 文件应以逗号分隔
  • R1 和 R2 文件必须保持相同的排序
  • 所有文件必须来自同一文库，测序模式和暗反应设置需保持一致
  • 不同实验或样本的数据不得合并分析

🟢 细胞识别参数

参数 描述与配置
--calling_method

🔧 默认：emptydrops

🔭 细胞识别方法

核心功能：用于区分真实细胞和空滴的算法选择
统计原理：通过不同算法分析 UMI 分布模式来识别真实细胞
精度影响：直接影响细胞识别的精确度和灵敏度
方法对比分析：
方法 技术原理 灵敏度 特异性 计算复杂度 适用场景
barcoderanks 基于总 UMI 计数的经验性阈值，通过 UMI 排序曲线拐点识别细胞 中等，易丢失低 RNA 含量细胞 中等，易误判高背景空液滴 低，快速运行 快速初步分析，可视化探索
emptydrops 基于表达谱统计检验（Dirichlet-multinomial），两步策略：初步筛选+统计检验 高，能检测低表达细胞 高，FDR 控制减少假阳性 高，依赖 Monte Carlo 模拟 标准分析（推荐），高精度需求
emptydrops 方法详细步骤：
  1. 初步筛选：根据预期细胞数量（--expectcells）捕获高 UMI 区域的细胞
  2. 统计检验：将 UMI 数量高于最小阈值（--minumi）的细胞与背景进行差异比较
  3. 结果判定：显著差异的被判定为真实细胞
--expectcells

🎯 默认：auto

📈 预期回收细胞数量

算法指导：为 emptydrops 算法提供初步筛选的指导信息
自动检测：auto 模式会根据 UMI 分布特征自动估算细胞数量
手动调节：根据实验设计和预期提供更精确的指导
设置建议策略：
  • 实验指导：建议填写为投入有效细胞数量的 50%
  • 无先验信息：若未提供投入细胞数，建议使用默认自动检测
  • 调试策略：可通过查看 UMI rank 图来估算合适的细胞数量
示例： 3000（预期 3000 个细胞）
--forcecells

🎯 覆盖

🔒 强制使用指定细胞数量

功能：强制流程使用确切的细胞数量，覆盖检测结果
选择：根据 UMI 的排序结果，选择排序靠前的特定数量的细胞
优先级：最高优先级 - 覆盖所有其他过滤条件
使用场景：
  • 标准化分析：对比实验需要保持一致的细胞数量
  • 下游分析：为下游分析软件提供固定数量的细胞
  • 特殊需求：针对特定实验设计的精确控制
  • 算法异常处理：当算法分析的细胞数量和细胞鉴定曲线图存在问题时的强制校正
示例： 5000（强制 5000 个细胞）
--minumi

🔢 默认：1000

📉 最小 UMI 数量阈值

质量控制核心：设定细胞级别的最低 UMI 数量要求，直接影响数据质量
生物学意义：UMI 数量反映细胞中捕获的 mRNA 分子数量，是评估细胞状态的重要指标
过滤机制：UMI 数量低于此阈值的细胞被认为数据质量不佳，将从后续分析中排除
平衡考虑：阈值过低保留低质量细胞，过高可能丢失有效细胞
优化设置建议：
  • 初次分析：使用默认值 1000，观察结果报告中 UMI 分布
  • 调整策略：根据 UMI 直方图和细胞数量统计进行优化
  • 数据类型影响：不同组织类型和实验条件可能需要不同的阈值设置

📊 细胞识别分析建议

💡 专业指导

细胞识别是单细胞分析的关键步骤，正确的参数设置和结果解读直接影响后续分析的质量和可信度。

🔍 细胞数量异常诊断与处理策略

异常类型 症状表现 可能原因 处理方案
细胞数量过低 检出细胞数 < 预期的50% UMI阈值过高、空滴污染严重、文库质量差 降低 --minumi，调整 --expectcells，检查原始数据质量
细胞数量过高 检出细胞数 > 预期的200% 细胞计数不准确、UMI阈值过低、背景噪声高 提高 --minumi，使用 --forcecells 限制数量
UMI分布异常 UMI rank图无明显拐点 测序深度不足、文库多样性差、技术失败（如反转录效率差，导致真实细胞信号很弱） 增加测序深度，重新构建文库

📈 细胞鉴定曲线图异常分析

曲线异常模式 生物学含义 技术解决方案
平缓下降无拐点 真实细胞和背景空滴难以区分 使用 --forcecells 设定保守的细胞数量，结合下游质控
多个拐点 存在不同细胞群体或双联体污染 选择主要拐点对应的细胞数，后续进行双联体检测和去除
陡峭下降 高质量细胞与背景区分明显，理想情况 使用默认 emptydrops 算法，可适当降低 --minumi
噪声波动严重 技术噪声高，数据质量差 增加 --minumi 阈值，考虑重新测序或优化实验条件

⚡ 最佳实践提示

首次分析建议使用默认参数获得初步结果，然后根据HTML报告中的统计信息和可视化图表进行针对性的参数调整。记录每次参数修改的效果，建立适合您实验条件的标准化分析流程。

🟢 文库设置参数

参数 描述与配置
--chemistry

🔧 默认：auto

🧪 试剂盒版本设置

核心功能：指定 scRNA 试剂盒的化学反应版本，决定条形码和 UMI 序列结构
自动检测：推荐使用 auto 模式，软件会根据数据特征自动识别试剂盒版本
版本影响：不同版本具有不同的条形码长度、UMI 长度和序列位置
支持的试剂盒版本：
版本条形码长度UMI长度适用场景
scRNAv1HT20bp (10+10)10bp第一代高通量试剂盒
scRNAv2HT20bp (10+10)10bp第二代高通量试剂盒
scRNAv3HT20bp (10+10)10bp第三代高通量试剂盒
scRNA5Pv120bp (10+10)10bp5'端测序专用试剂盒
自动检测机制：
  • 数据分析：检查前 200,000 个读段的序列结构
  • 版本判断：根据条形码和 UMI 位置模式识别试剂盒版本
  • 失败处理：无法识别时会提示手动指定版本
⚠️ 重要提示：错误的试剂盒版本设置会导致条形码和 UMI 提取失败
--darkreaction

🔧 默认：auto

🔬 暗反应循环设置

技术原理：控制 cDNA 和 oligo 文库中暗反应循环的处理方式
暗反应定义：测序过程中不进行荧光检测的循环，用于优化序列质量
双文库配置：需要分别为 cDNA 文库和 oligo 文库指定暗反应设置
自动检测：推荐使用 auto 模式，软件会自动分析序列长度分布
配置格式规范：

基本格式：<cDNA设置>,<oligo设置>

配置说明适用场景
auto自动检测（推荐）标准分析流程
R1R2R1和R2都有暗反应暗反应设计的文库
R1仅Read1有暗反应单端暗反应设计
unset无暗反应标准MGI协议
实际配置示例：
  • "R1,R1R2" - cDNA文库R1暗反应，oligo文库R1R2暗反应
  • "R1,R1" - 两个文库都是R1暗反应
  • "unset,unset" - 两个文库都无暗反应
自动检测逻辑：
  • 采样分析：检查前 200,000 个序列的长度分布
  • 模式识别：根据长度模式和固定序列信息推断暗反应设置
  • 验证机制：检查识别结果的合理性
--customize

⚙️ 可选

🛠️ 自定义序列结构配置

高级功能：用于非标准文库设计或特殊实验需求的精确序列结构定义
优先级：覆盖 chemistry 和 darkreaction 的自动检测结果
双重配置：需要分别为 cDNA 和 oligo 文库指定两次参数
坐标系统：使用 1-based 坐标系统（第一个碱基为位置1）
语法格式详解：

基本格式：<type>,<read>:<start>-<end>

类型说明示例
cb细胞条形码序列cb,R1:1-10
umiUMI（唯一分子标识符）umi,R1:21-30
R1Read1中的生物序列R1,R2:1-100
R2Read2中的生物序列R2,R2:1-100
配置示例解析：

cDNA 文库配置：

"cb,R1:1-10;cb,R1:11-20;umi,R1:21-30;R1,R2:1-100"
  • 第一个细胞条形码：R1 的 1-10 位置
  • 第二个细胞条形码：R1 的 11-20 位置
  • UMI 序列：R1 的 21-30 位置
  • 生物序列：R2 的 1-100 位置

oligo 文库配置：

"cb,R1:1-10;cb,R1:11-20;R1,R2:1-30"
  • 条形码提取：与 cDNA 文库相同位置
  • 序列长度：通常较短，用于条形码验证
使用注意事项：
  • 引号保护：参数必须用引号包围，避免 shell 解析错误
  • 坐标范围：不能超出实际读段长度
  • 双重指定：需要使用 --customize 两次，分别配置 cDNA 和 oligo
  • 验证检查：软件会验证配置的合理性
⚠️ 风险提示：错误的自定义配置可能导致数据丢失或分析失败，建议仅在标准配置无法满足需求时使用

🚩 分析设置参数

参数 描述与配置
--no_introns

⚡ 标志

📝 过滤内含子区域

核心功能：在分析过程中过滤掉来自内含子区域的 reads
生物学意义：仅保留来自外显子区域的 reads 进行表达量化
数据质量：去除正在加工的 pre-mRNA，提高结果可信度
适用场景：针对成熟 mRNA 的分析，避免未成熟转录本干扰
技术原理：
  • 过滤机制：基于 GTF 注释文件中的 exon 区域信息
  • 数据准确性：避免将未加工的原始转录本计入成熟基因表达
--end5

⚡ 标志

🔄 5'端转录组分析

核心功能：启用 5' 端单细胞转录组数据分析模式
技术特性：专门针对 5'端捕获的 mRNA 进行优化分析
适用试剂：需要使用支持 5'端测序的专用试剂盒
数据特点：5'端数据具有不同的序列结构和注释策略
⚠️ 重要提示：仅在使用 5'端 scRNA 试剂盒时使用此参数
--no_bam

⚡ 标志

📄 跳过 BAM 文件生成

核心功能：跳过 BAM 文件的生成步骤，节省时间和磁盘空间
性能优化：显著减少计算时间和存储需求
适用场景：仅需要基本表达矩阵的分析
功能限制：无法进行需要 BAM 文件的下游分析
资源节约效果：
  • 时间节省：减少 30-50% 的运行时间
  • 磁盘空间：节省大量磁盘存储空间（通常数 GB）
  • I/O 负载：显著减少磁盘 I/O 操作
建议：仅需要基本表达分析时使用，可显著提高分析效率
--sample_read_pairs

🎲 可选

🔬 读段对子采样

核心功能：从输入 cDNA FASTQ 文件中子采样指定数量的读段对
实用目的：用于快速测试或大数据集的初步分析
性能优势：显著减少计算时间和资源消耗
使用场景：参数优化、快速验证、资源限制环境
子采样策略：
  • 数据保留：仅对 cDNA 文件进行子采样，oligo 文件保持完整
  • 比例保持：保持 R1 和 R2 读段的配对关系
注意事项：
  • 代表性：采样数量越少，结果代表性越低
  • 重现性：相同参数的子采样具有一定的可重现性
示例： 100000000（100M个读段对）

💡 分析建议:

  • 首次分析建议使用默认参数，获得结果报告后根据需要调整参数
  • 双物种分析时，可通过基因名前缀区分不同物种来源的表达
  • 双物种分析结果中会自动生成物种分离的统计信息，帮助评估样本中不同物种的比例

Tip

📋 数据库构建技术说明：
