📋 Output Overview

This section provides comprehensive documentation for all output files generated by the DNBelab C Series single-cell analysis software. Each analysis pipeline (scRNA, scATAC, scVDJ) produces specific sets of output files designed for downstream analysis and visualization.

💡 Tip: Each output type includes quality metrics, processed data files, and interactive HTML reports for immediate analysis.

🧬 Single-Cell RNA Outputs

Pipeline: Gene expression profiling output files and quality metrics

Key Features:

  • Gene-barcode matrices in multiple formats
  • Comprehensive quality control metrics
  • Cell identification and filtering results
  • Interactive visualization reports

📊 ➡️ Complete RNA Output Guide / 中文指南

🧪 Single-Cell ATAC Outputs

Pipeline: Chromatin accessibility analysis output files and peak information

Key Features:

  • Peak-by-cell accessibility matrices
  • Fragment file for downstream analysis
  • TSS enrichment profiles
  • Cell filtering and quality metrics

📊 ➡️ Complete ATAC Output Guide / 中文指南

🦠 Single-Cell VDJ Outputs

Pipeline: V(D)J repertoire analysis output files and clonotype data

Key Features:

  • Full-length V(D)J sequence reconstruction
  • Clonotype identification and grouping
  • Cell-level receptor annotations
  • Comprehensive assembly metrics

Prerequisites: Requires completed 5' RNA-seq analysis
